📋매주 작업 순서

1
예배 날짜 확인
자동으로 이번 주 주일 날짜가 입력됩니다. 필요 시 수정하세요.
2
찬양팀 & 성가대 입력 (1·2부 개별)
2부 찬양팀 가사, 1·2부 성가대 이름 및 가사를 각각 입력합니다.
3
예배 순서 입력 (1·2부 공통)
찬송가 번호, 교독문 번호, 설교 제목, 성경봉독 책·장·절을 입력합니다.
4
설교찬양 악보 첨부
설교찬양 제목 입력 후 악보 .ppt / .pptx 파일을 업로드합니다.
· Praise&Worship 사이트에서 Wide 버전 다운로드 후 바로 업로드
5
특송 설정 (있는 경우)
1부 / 2부 각각 체크박스로 활성화 후 특송 유형, 특송자, 가사를 입력합니다.
체크 해제 시 특송 부분 없이 파일이 생성됩니다.
6
PPT 생성
하단의 1부 PPT 생성 / 2부 PPT 생성 / 1·2부 동시 생성 중 선택
완료 시 파일이 자동 다운로드됩니다.
파일명 예시: 20260622-주일예배(1부).pptx

성경봉독 본문

💡 책 이름은 검색창에 일부만 입력해도 목록이 필터링됩니다 (예: "요한" 입력 → 요한복음·요한일서 등 표시).
마지막절을 비우면 시작절 한 절만, 장만 입력하면 해당 장 전체를 가져옵니다.

⚙️템플릿 설정 (고급)

기본적으로 서버에 등록된 템플릿 파일을 사용합니다.
특정 주에 다른 템플릿을 사용하려면 하단 템플릿 설정 영역을 펼쳐 Google Drive 파일 ID를 입력하세요.

⚠️ 템플릿 Drive 파일은 링크를 가진 모든 이가 접근할 수 있도록 공유 설정이 되어야 합니다. 파일 URL에서 /d/ 뒤 ~ /edit 앞 부분이 파일 ID입니다.
예: https://docs.google.com/presentation/d/1KZzDoYvBLCd2ojV.../edit

🔧문제 해결

Q. 찬송가/교독문 슬라이드가 삽입되지 않아요
→ 서버에 해당 파일이 등록되어 있는지 확인
→ 파일명 규칙: 93장.pptx, 교독문 1번.pptx
→ 로그 창에서 구체적인 오류 메시지를 확인하세요
Q. 템플릿 파일을 찾을 수 없다는 오류가 나와요
→ 템플릿 설정에 Drive ID가 입력되어 있다면 비워보세요 (기본 템플릿 사용)
→ Drive ID를 직접 입력한 경우, 해당 파일 링크를 가진 모든 이가 접근할 수 있는 상태인지 확인하세요
Q. 성가대 가사가 잘못된 슬라이드에 들어가요
→ 가사 입력 형식을 확인하세요: 첫 줄에 [제목], 빈 줄로 슬라이드 구분
→ 특송 체크 여부와 관계없이 성가대/특송 슬라이드 구역은 분리되어 있습니다
Q. 생성 후 일부 슬라이드 내용이 이상해요
→ 로그 창의 메시지를 확인하세요
→ 해당 슬라이드만 수동으로 수정하시면 됩니다
Q. 성경봉독 본문이 생성되지 않아요
→ 책 이름이 목록에서 선택되었는지 확인하세요 (직접 타이핑만으로는 적용되지 않습니다)
→ 장 번호가 입력되어 있는지 확인하세요
→ 로그 창에서 "Godpia 조회 실패" 메시지 여부를 확인하세요
Q. 파일이 다운로드되지 않아요
→ 브라우저 팝업 차단 설정을 확인하세요
→ Chrome: 주소창 우측 다운로드 아이콘 클릭 → 차단 해제
